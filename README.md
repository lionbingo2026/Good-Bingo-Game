# 🎲 Good Bingo Game

Good Bingo Game is a Telegram live Bingo game built with:

- Python
- Flask
- python-telegram-bot
- SQLite
- Render deployment

## Features

✅ Telegram Bingo Bot  
✅ 75 Ball Bingo  
✅ 5x5 Bingo Cards  
✅ FREE center square  
✅ Automatic number caller  
✅ Player wallet system  
✅ 10 ETB registration bonus  
✅ Admin management  
✅ Live Bingo web board
